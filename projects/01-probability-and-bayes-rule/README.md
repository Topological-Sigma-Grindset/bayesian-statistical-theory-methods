# 1. Probability, Bayes' Rule, and Basic Bayesian Reasoning

## Overview

The basic structure of Bayesian inference: prior information, likelihood, posterior updating, and prediction. The goal is to translate probability calculations into reproducible R code and clear statistical explanations.

## Statistical goals

Focus on:

- Conditional probability
- Bayes' rule
- Prior, likelihood, and posterior distributions
- Simple simulation-based reasoning
- Interpreting uncertainty using probability statements
