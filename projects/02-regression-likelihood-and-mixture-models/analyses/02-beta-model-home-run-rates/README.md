# Analysis 02: Beta Model for Home-Run Rates

This analysis prepares Lahman player-season data, computes home-run rate, plots its empirical distribution, implements the beta log-likelihood, and saves a beta log-likelihood contour plot.

## Dependencies

```r
install.packages("Lahman")
```

## Run

```r
source("projects/02-regression-likelihood-and-mixture-models/analyses/02-beta-model-home-run-rates/code/02-beta-model-home-run-rates.R")
```
